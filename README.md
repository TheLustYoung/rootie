# rootie-shop

Демо интернет-магазина для бренда Rootie (rootie.co) (Ереван): статический сайт без сборки.

- **Hero:** кроссовок в центре экрана парит (вверх-вниз) и вращается по горизонтали. Модель строится в коде (Three.js, `js/sneaker.js`), внешних 3D-файлов нет. Цвета меняются кнопками под кроссовком.
- **Каталог:** карточки, фильтр по цвету, раздел Kids, выбор размера, корзина (запоминается в браузере).
- **Заказ:** форма в корзине собирает готовое сообщение и открывает WhatsApp (+374 41 773561) или Telegram (@rrrutti1). Онлайн-оплаты нет: её подключают позже через эквайринг банка.
- **Данные:** `data/products.json` (демо: названия, цены, размеры тестовые). Вместо 3D-миниатюр можно подставить настоящие фото магазина.

Запуск локально: `python -m http.server 8765` в этой папке, затем http://localhost:8765. Публикация: папка целиком на Vercel/Netlify (статический сайт).

## 3D-кроссовок в шапке

В шапке используется модель **Air Jordan 13 Retro Court Purple** (автор Switch 3D, Sketchfab) через официальный embed Sketchfab: файл модели не скачивается и в проект не копируется. Вращение по горизонтали даёт параметр `autospin` встроенного просмотрщика, парение это CSS-анимация. Ссылка на автора стоит в подвале сайта. Модель грузится 5–20 секунд (текстуры 4K): при медленной сети шапка сначала пустая.
Встроенный кроссовок на Three.js (`js/sneaker.js`) оставлен как запасной вариант: `http://localhost:8765/?model=procedural`.

## Загрузка 3D-модели (оптимизация)

- Текстуры не прогружаются заранее (`preload` выключен): модель показывается сразу, детали дорисовываются.
- Страница не ждёт модель: заставка с логотипом (preloader) исчезает, как только в кадре появился кроссовок, но не позже чем через 6 секунд; пока модель грузится, в шапке индикатор «Загружаем 3D».
- `preconnect` к серверам Sketchfab и запуск через Viewer API.
- На телефоне модель уменьшена отдалением камеры самого просмотрщика (а не рамкой), поэтому кроссовок целиком в кадре и без рамок.
- Самый быстрый вариант: положить GLB-файл модели в `models/` и показывать его через Three.js на своём хостинге (1–2 секунды, без подсказок и рамок Sketchfab). Для этого файл нужно скачать со Sketchfab (требуется вход в аккаунт и проверка лицензии).

## Структура по образцу nike.com

Маршруты (хэш-адреса, без сборки): `#/` главная · `#/shop[/Категория][?brand=&avail=&sort=]` каталог · `#/p/<id>` страница товара · `#/favorites` · `#/bag` · `#/store` магазин и чистка · `#/help`.

- Шапка: утилитарная полоса, логотип, меню с выпадающими блоками (mega menu), поиск, избранное, корзина, промо-полоса с каруселью сообщений.
- Главная: 3D-кроссовок, «В тренде» (бренды), карусель «Новинки», баннеры (магазин, чистка), разделы, карусель всех товаров.
- Каталог: заголовок со счётчиком, «Скрыть фильтры», сортировка, боковая панель (разделы, бренд, наличие), карточки с сердечком.
- Товар: галерея (на телефоне свайп с точками), цена, размеры с проверкой, «Добавить в корзину», «Спросить в WhatsApp», избранное, аккордеоны (подробнее, доставка, оплата, уход), «Вам также может понравиться».
- Корзина и избранное хранятся в браузере; заказ уходит готовым сообщением в WhatsApp/Telegram.
- Поиск: оверлей с популярными запросами и мгновенными результатами.
Данные: `data/products.json` (бренд, наличие, `new` для новинок).

## Каталог: фото без фона

Лайфстайл-фото убраны. Каталог собран из студийных (каталожных) картинок публичного канала магазина: инфографики Black Friday, цветовая таблица Moon Boot и фото Travis Scott Pink.
Каждый товар вырезан из белого фона в прозрачный PNG (`img/products/*.png`), у товаров есть цвета (кружки на карточке и миниатюры на странице товара, как на nike.com).
Пересборка: `python tools/build_catalog.py` (исходники и кадры лежат в `_source/`, на сайт не публикуются). Названия определены по картинкам: в `products.json` у каждого товара `"check": true`, это нужно подтвердить у магазина.
Цены из Black Friday (ноябрь 2025) не использованы: они устарели. Показано «Цена по запросу».
Фото небольшие (около 270 px по ширине), поэтому для боевого сайта лучше взять оригиналы у магазина.
